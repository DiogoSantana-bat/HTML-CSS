Listas Ordenadas e Desordenadas

Listas Ordenadas

Para fazer uma lista ordenada é muito simples. Simplesmente utilize a tag <ol> e coloque cada item dentro da tag em outra tag que é <li>.

  1. Comprar pão
  2. Arrumar a casa
  3. Fazer almoço
  4. Lavar roupas

Também é possível personalizar sua lista, utilizando o parâmetro type e o start serve para definir aonde vai começar sua lista.

Ex: <ol type "" start "">

Lista Não Ordenadas

Também é muito simples. Utilize a tag <ul> para criar uma lista não ordenada e utilize as tags <li> dentro dela também.

  • Arroz
  • Feijão
  • Carne Moída
  • Tomates
  • Creme de Cebola
  • Orégano
