Mais formatações (não, ainda não acabou)

Código-fonte

Se eu quiser escrever um código num documento, é só colocá-lo na tag <code> e a fonte vi ficar monoespaçada .

Ex: Sempre digite hello world ao usar uma linguagem pela primeira vez.

Observação: sempre utilize a tag <pre> antes para pôr a tag <code> dentro dela para o código ficar organizado, se não, vai ficar um do lado do outro.

Ex: 

             
    <?php
        echo "Hello, World!";
    ?>

Citações (de novo?)

Utilize a tag <q> entre uma citação.

Segundo Osamu Dazai em seu livro Decínio de um Homem:

Algumas pessoas têm um pavor tão mórbido dos demais seres humanos que acabam desejando ver com os próprios olhos aparições cada vez mais monstruosas.
