Formatações mais utilizadas

Negrito ou Destaque

Não, não foi o que eu quis dizer...

Enfim, se eu quiser que meu texto fique em negrito, há duas formas para eu fazer isso. Na verdade, em todas as tags que eu mostrar aqui, tem dois jeitos de fazer: a maneira semântica e a não semântica.

Ah, já ia me esquecendo. O negrito serve justamente para destacar alguma palavra, frase, ou parágrafo em um texto que seja de suma importância.

Exemplo: "É o seguinte, parceiro. Vou te dar duas escolhas. Você prefere comer um homem no corpo da sua namorada ou comer sua namorada no corpo de um homem?"

A tag semântica para negrito é a <strong> e a não semântica é a <b>.

Itálico ou Ênfase

Tá bom, chega dessas piadas preconceituosas.

O itálico serve para destacar palavras estrangeiras, citações, títulos de obras, termos técnicos, etc...

Ex: "Certa vez, o ilústre filósofo e cantor MC Magrinho disse: Você sabe o que é Pumba la Pumba? É o barulho do meu saco batendo na sua bunda."

Há várias tags semânticas do itálico para certos tipos de situações. Para ênfase, existe o <em>, para citações, existe o <cite>, para endereços, existe o <address>, para definições, existe o <dfn>, e a forma não semântica é o <i>.

Observação: Não é recomendado o uso do itálico junto com o negrito.

Marcador de textos (Não faria nenhum sentido se o HTML não tivesse uma maneira de marcar textos)

Para marcar um texto também é bem simples, é só utilizar a tag <mark> que seu texto estará marcado como se você tivesse passado um marca-textos por cima.

Mudando a cor da marcação

"Ah, mas eu não gostei da cor do marcador ou o fundo do meu site é amarelo." O correto seria mudar isso no CSS, mas vou ensinar apenas para demonstrar que fazer isso no HTML é possível, porém não recomendado.

Toda tag (ou a maioria das tags) tem um parâmetro de estilização que pode ser utilizado tanto no CSS quanto no HTML, que é o style.

Por exemplo, se eu quiser mudar a cor da minha marcação para rosa, eu utilizo o <mark style= "background-color: hotpink>.

Viu como é fácil? 👍

Colocando a mesma cor em todas as marcações

"Mas se eu tiver 300 textos para marcar e não quiser fazer isso individualmente?" Isso também é possível, porém não recomendado fazer no HTML também.

Dentro do <head>, você pode criar uma tag <style> e dentro dela, você cria o seguinte código:


<style>

mark {

background-color: "hotpink";

}

</style>

E pronto, todas as suas marcações estarão da mesma cor!

Como fazer um texto grande e um texto pequeno

Se você utiliza os h1, h2, h3, etc... para textos grandes e pequenos, você está redondamente enganado. Há outra maneira de você fazer isso sem cagar o seu código.

Para textos grandes, você utiliza o <big> e para textos pequenos, você utiliza o <small>.

Tag <big> em desuso

"Mas o <big> ficou em vermelho no meu código. Porque isso aconteceu?"

Bem, essa tag caiu em desuso depois do lançamento do HTML5 pois não faz muito sentido ter uma tag para aumentar uma letra ou uma palavra quando se pode formatar no CSS. A tag <small>, por outro lado, é utilizada para colocar informações menos importantes em seu site.

Como colocar um texto que foi deletado

Um texto deletado é um texto que é para ser lido, porém desconsiderado.

Para colocar um texto deletado, simplesmente utilize a tag <del>.

Ex: "Eu gosto tanto da Vanusa mesmo que ela tenha trepado com o meu marido todas as vezes que ela fica trabalhando de empregada na minha casa."

Como colocar um texto inserido

Um texto inserido é quase que o contrário do texto deletado. É um texto feito para dar ênfase que foi posto depois.

Para colocar um texto inserido, simplesmente utilize a tag <ins>.

Ex: "Eu odeio o Kilder por que ele sempre come na minha casa e vai embora logo em seguida."

OBS: O texto inserido é a forma semântica da tag <u>, que é o texto sublinhado.

Como colocar um texto sobrescrito e subscrito

Um texto sobrescrito serve para inserir coisas tipo: x20+3

Para fazer isso, utilize a tag <sup>.

Um texto subscrito é a mesma coisa só que ao contrário, como por exemplo: H20.

Para fazer isso, utlize a tag <sub>.
