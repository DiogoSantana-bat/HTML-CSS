Principais formatações

Negrito (comum)

Negrito é simples, é só fazer <b> e sua palavra ficará assim!

Negrito (semântica)

Agora para fazer o negrito "semanticamente" você usa a tag <strong> e sua frase ficará desta forma!

Itálico não semântico (mammamia)

Para fazer o itálico, é só usar a tag <i> e sua frase ficará desta forma!

Itálico (semântica)

Para fazer o itálico de forma semântica, você digita a tag <EM> e sua frase ficará desta forma!

Texto marcado

Você pode marcar o texto utilizando a tag <MARK> e sua frase ficará desta forma!

E também você pode mudar a cor da marcação utilizando <mark style="background-color:> e sua frase ficará desta forma!

Texto grande e pequeno

Agora para fazer um texto grande e pequeno, é assim:

Grande é a tag <big> (esse está defasado, mas tudo bem)

Pequeno é a tag <small>

Texto Deletado

Para mostrar que um texto foi deletado, utilize a tag <del> e sua frase ficará desta forma!

Texto Inserido

Para mostrar que um texto foi inserido depois, utilize a tag <ins> e sua frase ficará desta forma!

Também tem a tag <u>(mas é de uma forma não semântica)

Texto sobrescrito

Para inserir coisas do tipo X20+3, utilize a tag <sub>

Texto subscrito

Para inserir coisas tipos H2O, utilize a tag <sub>
